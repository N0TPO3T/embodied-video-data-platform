## 依赖与风险

- **文本模型端点**：规范化依赖百炼文本模型，需确认 `QWEN_BASE_URL` 工作空间可用文本模型（P2 前置）。
- **提示词重构影响面**：P3 会改 `video_qc_v1 → v2`，`prompt-loader` 版本校验、`quality-lab`、现有测试快照都要同步，建议 P3 单独分支验证。
- **`ai-quality-lab` 实验页**：作为独立链路，需同步新框架提示词，否则实验页与主流程不一致。
- **提交数量无上限**：未设单人上限，依靠硬性否决 + 近似重复兜底，后续可按需补频率限制（方案 9.6 已注明）。
