# 具身智能视频数据平台 · 用户使用手册

> 面向数采人员、团长、平台管理员的使用说明。
> 更新日期：2026-08-24

---

## 1. 平台简介

具身智能视频数据平台（Embodied Data，品牌标识「自然常数」）是一个面向具身智能视频数据生产的外包平台，覆盖「视频采集 → AI 质检 → 人工复核 → 积分结算 → 数据资产交付」的完整流程。

- **数采人员**：按采集指南拍摄第一人称操作视频并上传，查看质检结果与积分。
- **团长**：管理本团队成员、查看团队数据与质检结果、核对团队积分。
- **管理员**：管理账号与团队、规则与标签、AI 质检运维、积分周期、数据资产与公开站点。

平台不含真实提现/打款流程，积分用于内部结算与线下对账。

## 3. 数采人员操作指南

登录后左侧导航包含以下页面。

### 3.1 我的工作台

个人数据概览：上传数量、质检通过率、待质检/待复核数据、可结算积分等汇总指标。

### 3.2 任务大厅

1. 点击「任务大厅」，查看当前所有**进行中**的采集任务卡片（任务标题、场景、要求摘要、每分钟积分单价）。
2. 已暂停的任务会置灰并标记「已暂停」，不可提交；已关闭的任务不在大厅展示。
3. 点击任务卡片上的「去采集」，自动携带该任务进入上传页。
4. 任务要求由管理员发布，视频必须符合所选任务的要求，否则 AI 质检会按「任务符合度」判定并可能进入人工复核。

### 3.3 上传视频

1. 点击「上传视频」，**先选择采集任务**（可从任务大厅跳转带入），阅读该任务的要求（含硬性/一般条目）并勾选「我已阅读并理解该任务的采集要求」。
2. 选择本地 **MP4 / MOV** 文件（单个最大 2 GiB），勾选「数据使用权、隐私规范与敏感内容处理」授权确认。
3. 文件分片上传，支持**暂停 / 继续 / 取消 / 失败重试**。
4. 刷新页面或更换设备后，重新选择**同一个原始文件**（同名、同大小、哈希一致）即可**恢复未完成的上传**。
5. 上传完成后自动进入媒体解析与 AI 质检队列，无需手动操作；视频将归属所选任务，并按任务要求进行质检与定价。

### 3.4 我的数据

查看本人所有提交的视频列表，支持搜索、状态筛选、分页；列表展示所属任务场景；点击条目进入详情，可在线预览视频（HLS 流畅预览 / 低码率回退）、查看媒体信息与质检状态。

### 3.5 质检结果

查看已出 AI 终态结论或待人工复核的提交，进入详情可查看五维评分、问题区间、证据帧与改进建议；提交归属任务时，详情还会展示**任务符合度**（场景匹配 + 每条要求的符合/部分符合/不符合判定）。

> 质检结果为平台自动化/人工判断，用户前台不会展示内部提示词、模型版本等技术细节。

### 3.6 积分明细

查看本人积分：按已锁定积分周期、周期明细、待锁定提交数据汇总；可查看每条视频的积分快照、结算比例与所属任务单价。

### 3.7 采集指南

拍摄规范说明（第一人称、双手入镜、画面质量、任务真实性等要求），上传前请先阅读；发布任务后任务要求以任务详情为准。

### 3.8 个人资料

修改自己的密码（需先验证当前密码）、查看账号信息。改密会使其他设备上的登录会话失效。

## 4. 团长操作指南

团长登录后进入团队工作台，左侧导航包含以下页面。

### 4.1 团队工作台

团队近 30 日指标、近 7 日趋势、场景分布、成员贡献、待关注与失败任务等汇总。

### 4.2 成员管理

查看本团队数采成员，可新增成员、改名、重置密码、停用/启用本团队成员账号。

### 4.3 团队数据

本团队提交数据：服务端搜索、状态筛选、分页；可按当前筛选结果**导出 CSV**。

### 4.4 质检结果（只读）

查看本团队**未锁定且质量通过**的数据；未通过、敏感隔离、疑似重复待确认数据不会出现在普通积分候选中。

### 4.5 团队分析

团队成员通过率、人均有效时长、场景分布、成员贡献等分析视图。

### 4.6 团队积分

本团队积分汇总：按积分周期与待锁定提交数据计算，支持导出明细。

## 5. 管理员操作指南

管理员登录后进入运营总览，功能较多，按页面说明如下。

### 5.1 运营总览

平台级汇总：视频提交数、质量通过率、可交付资产、有效账号、处理流水线状态。

### 5.2 数据提交

全平台提交列表，支持服务端搜索、状态筛选、分页、CSV 导出；查看真实周期锁定状态与所属任务。

### 5.3 任务管理

1. **创建任务**：填写任务标题、说明、场景名称（输入时带标签字典补全）、任务要求（自由填写）与每分钟积分单价（可留空回退全局规则）。
2. **AI 要求规范化**：保存草稿后点击「规范化」，AI 会把自由填写的要求转换为结构化条目（硬性/一般 + 判定依据），管理员可**预览、增删改、切换硬性/一般**后确认。
3. **发布**：确认规范化要求后点击「发布」；**全新场景会自动加入标签字典**并生成新版本；发布后数采人员即可在任务大厅看到并提交。
4. **暂停 / 恢复 / 关闭**：暂停只阻止新提交（已提交数据继续处理）；关闭不可逆，关闭后不可再提交。
5. 编辑已发布任务后需**重新规范化并确认**，发布为新的任务版本；已提交数据按提交时锁定的任务要求与单价继续质检与结算。

### 5.4 AI 任务

AI 质检队列运维：队列快照、发布耗时、Worker 心跳、机器信息、当前任务、处理耗时、完成/失败数；对**失败任务可填写原因后重跑**，对**超时任务可一键重新排队**。

### 5.5 质量复核

对 AI 结果进行人工复核：查看复核候选（质量通过且未入周期的数据），确认/解除**近似重复**候选，调整最终分、问题区间、原因，写入审计留痕。敏感内容可**隔离 / 解除隔离**。任务符合度不通过（硬性要求未满足或场景不匹配）的数据也会进入复核队列。

### 5.6 数据资产

待交付资产、最近入库资产、交付包管理；创建交付包、生成资产 CSV 清单、短期签名下载链接、zip/tar 一键归档下载。

### 5.7 用户与团队

- 新增/编辑/启停团队，指定**唯一团长**，调整**团队单价**（每分钟积分）。
- 新增/编辑管理员、团长、数采账号；调整团队归属；重置密码；停用/启用账号。
- 跨团队调配账号、原子更换团长。角色/团队变更、重置密码会撤销相关账号旧会话并写审计。

### 5.8 标签与规则

- **标签体系**：管理场景 / 动作 / 对象 / 质量问题四类标签，支持**新增、编辑、删除**（每次修改生成新版本快照）；任务发布自动新增的场景可在此停用。
- **质量规则**：发布质量规则版本、通过阈值、说明。
- **系统提示词**：编辑 AI 质检系统提示词（每次保存创建新版本，只影响之后开始的任务）。
- **稀缺奖励配置**：配置任务稀缺度分档系数与权重（见 6.3）。

### 5.9 积分规则

- 发布积分规则版本：默认每分钟积分、**质量系数分档**（可增删改档位）、说明。
- **任务定价**：视频的实际每分钟积分单价按「任务单价 > 团队单价 > 全局默认」的优先级确定，任务单价在任务创建时设置。
- 生成/预览**积分周期**并锁定；锁定后每个视频条目有快照（含所属任务信息）。
- **条目调整**：锁定后如个别视频评分/无效时长需要修正，可对单条视频做调整，系统重算比例与积分并留痕。

### 5.10 公开数据配置

从质检通过数据生成**脱敏快照**（官网指标、场景占比、公开文案），发布后官网首页展示最新汇总。

### 5.11 操作日志

审计日志：按关键词、操作人、动作、时间范围筛选、分页，支持 CSV 导出。

## 6. 核心业务说明

### 6.1 视频质检（五维评分）

每个视频按五个维度评分，每维满分 20 分、总分 100 分，`每维得分 = 20 × 该维系数`：

| 维度 | 内容 |
|---|---|
| 第一维 | 第一人称与构图规范性 |
| 第二维 | 手部、前臂与操作对象完整度 |
| 第三维 | 视频与帧质量（分辨率/帧率/清晰/曝光/稳定/连续） |
| 第四维 | 任务维度：归属任务时按任务符合度（场景匹配 + 要求逐条判定），否则按任务真实性与完整度 |
| 第五维 | 任务价值与独特性（库存稀缺 + 独特性） |

常见终态：`通过（scored）`、`硬性否决（hard_reject）`、`待人工复核（review_pending）`、`系统失败（system_failed）`。命中隐私/安全风险或人工标记的视频进入**隔离**状态。

### 6.2 积分计算

```
积分 = 每分钟积分 × 有效计费时长(分钟) × 结算比例
```

- **每分钟积分**：默认 `12 分/分钟`，可由团队单价覆盖。
- **有效计费时长**：总时长减去无效片段（黑屏、冻结、无关内容等）。
- **结算比例**：由最终得分落入的**质量系数分档**决定，默认分档：

| 得分区间 | 结算比例 | 档位名 |
|---|---:|---|
| 80 ~ 100 | 1.00 | 优质 |
| 70 ~ 79 | 0.85 | 合格 |
| 60 ~ 69 | 0.70 | 基础 |
| 0 ~ 59 | 0 | 不计分 |

> 分档可由管理员在「积分规则」中修改。得分低于通过阈值（默认 60）或命中硬性否决时结算为 0。

**积分周期**：管理员把一段业务时间内的通过数据**锁定**为一个周期，每条视频生成积分快照；锁定后如需修正，走「条目调整」留痕。

### 6.3 任务稀缺奖励（第五维）

平台按「**场景 → 标准任务 → 任务变体**」三层统计存量，对**存量较少的场景给予更高系数**（稀缺奖励）：

```
C_inventory = 0.2 × C_场景 + 0.5 × C_标准任务 + 0.3 × C_变体
```

默认分档：

| 同层存量（条） | 系数 | 档位名 |
|---:|---:|---|
| 0 ~ 5 | 1.00 | 稀缺 |
| 6 ~ 20 | 0.90 | 较少 |
| 21 ~ 50 | 0.75 | 中等 |
| 51 ~ 100 | 0.60 | 较多 |
| 101 以上 | 0.50 | 饱和 |

> 在数据量积累不足（冷启动）或任务未成功归类时，该系数按 1.00 计算，不影响正常计分。

### 6.4 数据资产交付

质检通过并完成结算的视频进入「可交付资产」，管理员可打包为交付包，提供资产清单 CSV、短期签名下载链接、zip/tar 归档下载。

## 7. 注意事项

- 仅支持 **MP4 / MOV**，单文件最大 **2 GiB**，分片 16 MiB。
- 上传地址有效期 15 分钟；长时间不操作可能需重新获取。
- 修改密码、重置密码、更换团队/角色会使旧登录会话失效，需重新登录。
- 完全重复的视频会被拦截；近似重复会进入待确认，管理员确认前不参与积分锁定。
- 浏览器对图标等静态资源有缓存，界面更新后如显示异常，请**强制刷新（Ctrl/Cmd + Shift + R）**。
