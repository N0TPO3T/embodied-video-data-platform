# 本地 NestJS 视频数据平台重构设计

- 日期：2026-08-07
- 状态：用户已确认
- 目标：保留现有 Web 界面，将浏览器演示数据和 Cloudflare D1 后端逐步替换为可在本地完整运行的生产型后端

## 1. 已确认的总体方案

- 保留现有 React 19、TypeScript 5.9、Next/Vinext Web 界面。
- 不建设小程序、移动端 App、钱包、提现和线上打款。
- 新后端使用 NestJS 模块化单体。
- PostgreSQL 是业务数据唯一事实来源。
- Redis 用于缓存、限流和短期状态。
- RabbitMQ 承载媒体处理、AI 评估、向量生成和结算任务。
- MinIO 作为本地 S3 兼容对象存储。
- Qdrant 存储视频和片段的相似度向量，PostgreSQL 保存向量业务索引和审计信息。
- FFmpeg/FFprobe 在独立媒体 Worker 中运行。
- 质检和向量均只调用真实模型，不提供 Mock 模式。
- 模型通过通用 Provider 接口接入；首个质检模型使用千问视觉模型，首个向量模型使用 `qwen3-vl-embedding` 1024 维。
- 本地 AI 媒体读取通过自动启动的 Cloudflare Quick Tunnel 完成，只开放带一次性令牌的媒体读取端点。
- 模型密钥只放在被 Git 忽略的本地环境文件中。未配置密钥时平台可启动，但 AI 任务保持“模型未配置”，不会生成结果。

## 2. 数据迁移边界

- 迁移 D1 中的账号、角色、团队归属、账号状态和账号审计。
- D1 现有明文原型密码在迁移时转换为 Argon2id 摘要；明文不写入日志或迁移报告。
- 不迁移旧会话，迁移完成后所有用户重新登录。
- 不迁移浏览器 DemoStore 中的任务、视频、评分、提现或结算数据。
- D1 在切换后只作为只读备份，不再承担运行时请求。
- 新数据库提供明确标记为测试数据的初始化记录；测试记录不冒充实时 AI 输出。

## 3. 角色与权限

- 管理员可管理所有团队和账号，可查看全量数据，可人工修正最终质检结果。
- 团长只能查看自己的团队，可为本团队创建数采账号、修改显示名称、重置密码和启停账号。
- 数采人员只能查看自己的账号、视频、质检和结算明细。
- 团长和数采人员均不可修改 AI 原始结果或最终质检结果。
- 至少保留一个启用状态的管理员。
- 密码重置、账号停用、团队或权限变更会撤销受影响账号的全部会话。
- 关键写操作必须记录操作者、对象、原因或摘要、修改前后值和时间。

## 4. 视频与 AI 流程

```text
Web 创建上传会话
  → 浏览器分片直传 MinIO
  → API 确认对象和校验值
  → RabbitMQ 媒体任务
  → FFprobe/FFmpeg 提取信息、检测无效区间、生成 AI 片段
  → 真实质检 Provider
  → 真实 Embedding Provider
  → Qdrant 相似度召回
  → 评分结果和版本写入 PostgreSQL
  → 每日结算任务生成锁定明细
```

模型失败只重试同一模型并使用指数退避。超过最大次数后标记为 `system_failed`；管理员可指定模型和版本重新运行。系统不自动切换供应商，也不生成替代结果。

## 5. 评分与结算

- 五个维度各 20 分，每维按 `20 × 系数` 计算，总分 100。
- 有效时长排除黑屏、冻结、无关内容和人为垫时；任务所需的正常等待计入有效时长。
- 低价值片段按命中系数和时长占比折算任务真实性与价值得分。
- 80–100 分结算比例 1.0。
- 60–小于 80 分结算比例 0.8。
- 40–小于 60 分结算比例 0.6。
- 小于 40 分结算比例 0.4。
- 硬性不合格独立于分数，结算比例为 0。
- 每日自动锁定前一日结算；修正只能通过冲正和调整明细完成。
- 平台记录应付金额与明细，但不持有资金、不提供在线提现；团长线下支付。

## 6. 本地运行

Docker Compose 最终运行：

- `web`
- `api`
- `postgres`
- `redis`
- `rabbitmq`
- `minio`
- `qdrant`
- `media-worker`
- `ai-worker`
- `scheduler`
- `cloudflared`

Web 默认访问 `http://localhost:3000`，API 默认访问 `http://localhost:4000/api/v1`。基础设施健康状态通过 API 的 readiness 接口统一展示。

## 7. 分阶段交付

1. 基础设施、PostgreSQL 账号体系、D1 账号迁移和 Web 登录切换。
2. MinIO 分片直传、视频状态机、FFprobe/FFmpeg 媒体处理。
3. 通用真实模型接口、评分规则、Qdrant 相似度和人工复核。
4. 任务库存、统计、每日结算、测试业务数据和现有页面完整接线。
5. 全流程、权限、重试、恢复、容量和本地启动验收。
