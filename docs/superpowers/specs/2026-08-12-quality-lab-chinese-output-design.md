# AI 视频质检中文输出设计

## 目标

AI 视频质检页面中面向用户的结果全部使用简体中文，同时保持 `video_qc_result_v1` 的 JSON 字段名、枚举值和原因代码不变，确保后续迁移到正式系统时接口兼容。

## 方案

1. 模型层：在 V1 系统提示词及每次请求的输出要求中，明确要求 `task_summary`、`summary`、`description`、`calculation_trace`、`recommendations` 和 `review_reasons` 等自然语言字段使用简体中文。
2. 质量门禁：模型响应通过结构校验后，再检查上述非空自然语言字段是否包含中文。英文结果视为不合格，复用现有结构修复调用要求模型改写；二次输出仍不符合时任务进入系统失败，不把英文结果交给页面。
3. 展示层：页面把评估状态、扣分严重程度和已知原因代码映射为中文。下载的原始 JSON 继续保存英文技术枚举，避免破坏 API 契约。
4. 测试：覆盖提示词中文约束、英文结果触发修复、修复要求和页面中文映射。

## 错误处理

英文自然语言结果与结构错误使用同一条修复链路，并在修复提示中列出不符合要求的字段路径。最多修复一次，避免无限调用和不可控费用。

## 非目标

- 不翻译 JSON 字段名、模型名、规则版本、任务 ID 或原因代码的原始值。
- 不修改五维评分、硬性否决和结算规则。
