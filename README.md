# Embodied Video Data Platform

一个面向具身智能视频数据生产的可点击平台框架，覆盖公开官网、账号密码登录、数采人员、团长和平台管理员四类界面。

当前版本的账号、登录会话和账户审计记录已接入持久化数据库；视频上传、AI 处理、质量复核、数据入库、每日结算和提现审核等业务数据仍在浏览器会话内模拟。对象存储、AI 推理和支付接口暂未接入。

## 已实现范围

- 公开官网：平台定位、公开指标、场景能力、生产流程、质量保障和体验入口。
- 数采人员：视频上传、我的数据、质检详情、收入提现、采集指南和个人资料。
- 团长：成员管理、团队数据、结算前复核、团队分析和团队收入。
- 平台管理员：全平台提交、AI 队列、质量复核、数据资产、用户团队、规则、结算、提现审核、公开配置和审计日志。
- 核心规则：角色数据隔离、质量系数、有效时长、预计收入、结算后不可修改和提现金额校验。

## 本地运行

环境要求：Node.js 22.13 或更高版本，pnpm。

```bash
cd web
pnpm install
pnpm dev
```

默认访问地址为 `http://localhost:3000`。

## 验证

```bash
cd web
pnpm test
pnpm typecheck
pnpm build
pnpm test:render
```

## 交互演示

除账号、登录会话和账号审计外，页面中的业务操作会在当前浏览器会话内更新模拟数据，刷新页面后会恢复初始状态。可优先体验：

- 团长查看成员详情与指标；新成员账号需由管理员统一创建。
- 管理员新增或配置账号，新建价格规则版本并维护标签。
- 管理员预览并生成结算批次，将已结算数据组成交付包。
- 通过顶部通知面板、成功提示和操作日志观察操作结果。

短信、文件导出、真实支付和交付包下载仍为演示占位，会给出明确的界面反馈，不会触发外部服务。

## 工程结构

```text
web/
├── app/                  # vinext / Next 应用入口、全局样式和元数据
├── src/app/              # 客户端路由与角色边界
├── src/domain/           # 领域类型和纯业务计算
├── src/data/             # 演示数据与内存状态仓库
├── src/components/       # 表格、状态、复核抽屉等公共组件
└── src/features/         # 官网、登录、数采、团长和管理员页面
```

页面通过统一的演示数据仓库读取和更新业务状态，账号与登录会话由服务端 API 和持久化数据库管理。后续接入真实业务后端时，可以逐步替换演示仓库，同时保留现有页面结构和领域计算。
